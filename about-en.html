About the Project

About the Project

An independent research website about Poland and its major cities, created to present historical, geographical, demographic, economic, and cultural information in a structured, readable, and accessible way. The website is divided into separate research pages, with images, credits, floating image modals, and a mobile-friendly layout.

Organized Structure

The main index links to independent research pages: the Poland page, city pages, and the about page. This makes it easy to expand the website without overloading a single file.

Images and Credits

Images are stored in the assets/images/ folder, and attribution credits are added on pages where a license or source credit is required.

Mobile Friendly

The design uses dark research cards, rounded corners, and a layout that works well on small screens, including image opening through floating modal windows.

Website Purpose

The purpose of this website is to build a clear and expanding research hub about Poland: the country itself, the capital city Warsaw, and later additional major cities such as Kraków, Wrocław, Łódź, and Poznań.

Each page is designed to combine quick facts with expanded research text: etymology, foundation period, founders or formative figures, reasons for development, geography, demography, economy, history, and culture.

The website is built so that more pages, images, credits, and sources can be added gradually without breaking the existing structure.

Rights and Credits Note

This website is intended for research, learning, and educational visual reference. When images from free external sources are used, the file name, source, and license should be credited according to the relevant usage requirements.

Original images created for the website are stored in the assets/images/ folder. When an image comes from Wikimedia Commons or another external source, a clear credit should be added to the page where the image appears.
