Sources and Credits

This page centralizes the credits, image sources, file names, and license information for the visual assets used on the website. Its purpose is to keep the project transparent, organized, and compliant with attribution requirements when images from free sources such as Wikimedia Commons are used.

Clear Attribution

For every externally sourced image, the file name, source, license, and relevant links should be listed when required.

Central Image Folder

All website images are stored in assets/images/ to keep the file structure clean.

Educational Use

The website is intended for research, learning, and educational visual reference, with attention to proper credits.

Future Working Rules

  • New images: All new images should be stored in assets/images/.
  • File names: Use lowercase English file names with hyphens instead of spaces.
  • Wikimedia Commons images: Check whether attribution is required, what the license is, and whether reuse is allowed.
  • On-page credits: When an image appears on a research page, it is recommended to include a short credit beneath it.
